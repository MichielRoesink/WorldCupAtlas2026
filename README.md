# CupAtlas

**An interactive world atlas for experiencing international football tournaments through the map.**

CupAtlas is an independently developed web application that places the world map at the centre of the football tournament experience.

Instead of approaching a tournament primarily through tables, lists and brackets, CupAtlas uses geography as its main interface. Countries, matches, tournament progress and contextual information are brought together on a single interactive world map.

## The concept

Everything in CupAtlas revolves around the map.

The world map remains the primary interface throughout the experience. Tournament information is presented in geographical context rather than replacing the map with traditional pages or dashboards.

CupAtlas is being developed initially around the 2026 FIFA World Cup.

## Current features

CupAtlas currently includes, among other things:

- Interactive world map
- Tournament stages and timeline
- Country tournament status
- Live and upcoming match information
- Country information panels
- Previous and next matches
- Population and FIFA ranking information
- Capital cities
- Local time at each country's capital
- Daylight information
- Club connection layers
- Live geographical match visualisation
- Astronomical day/night calculations
- Dynamic map visual effects

## Country data

CupAtlas contains geographical and time-zone information for approximately 245 countries and territories.

This information is used to connect football tournament data with geographical context.

## Development

CupAtlas is an independently developed project.

The application is currently under active development and functionality, design and data structures may change considerably before a public release.

## Project status

**Development / pre-release**

CupAtlas is not currently presented as an official FIFA product.
